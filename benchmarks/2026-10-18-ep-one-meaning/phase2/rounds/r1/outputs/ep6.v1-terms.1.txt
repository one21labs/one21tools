## scripts/common.py (new)

```python
"""Shared API config, logging and HTTP retry. BASE_URL is the single source of truth for the API host."""
import logging
import time

import requests

BASE_URL = "https://api.newhost.io/v2"

logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s %(levelname)s %(name)s: %(message)s",
)


def get_logger(name):
    return logging.getLogger(name)


def get_with_retry(url, retries=3, backoff=1.0, timeout=10):
    log = get_logger("http")
    for attempt in range(1, retries + 1):
        try:
            log.info("GET %s (attempt %d/%d)", url, attempt, retries)
            resp = requests.get(url, timeout=timeout)
            resp.raise_for_status()
            log.info("OK %s -> %d", url, resp.status_code)
            return resp
        except requests.RequestException as exc:
            log.warning("Failed %s: %s", url, exc)
            if attempt == retries:
                log.error("Giving up on %s after %d attempts", url, retries)
                raise
            time.sleep(backoff * 2 ** (attempt - 1))
```

## Notes

- **Imports:** `from common import ...` works when you run `python scripts/fetch_users.py`, because `scripts/` is on the path. If you run the scripts as modules or from elsewhere, adjust the import.
- **Retry behavior:** it makes 3 attempts with 1s and 2s waits and a 10s timeout per request. Any HTTP error status (4xx too) is retried, which is fine for a demo.
- **Not run:** I haven't run any of this, so do a quick `python scripts/fetch_users.py` and `python scripts/fetch_orders.py` before the demo.
