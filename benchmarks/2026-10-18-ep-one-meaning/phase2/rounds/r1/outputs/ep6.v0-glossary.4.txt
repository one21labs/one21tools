## scripts/config.py (new file)

```python
"""Source of truth for the API base URL and the shared retrying HTTP session."""
import logging

import requests
from requests.adapters import HTTPAdapter
from urllib3.util.retry import Retry

BASE_URL = "https://api.newhost.io/v2"


def setup_logging():
    logging.basicConfig(
        level=logging.INFO,
        format="%(asctime)s %(levelname)s %(name)s: %(message)s",
    )


def make_session():
    retry = Retry(
        total=3,
        backoff_factor=1,
        status_forcelist=(429, 500, 502, 503, 504),
        allowed_methods=("GET",),
    )
    session = requests.Session()
    session.mount("https://", HTTPAdapter(max_retries=retry))
    return session
```

## Notes

- **Imports:** `from config import ...` works when you run `python scripts/fetch_users.py` from any directory, because Python puts the script's folder on the import path. It would break if you run the scripts as modules (`python -m`).
- **Retries:** the scripts retry up to 3 times with backoff on 429 and 5xx responses and on connection errors. `timeout=10` is new, because without it a hung connection never gets retried.
- **Smoke test before the demo:** run both scripts once. The logs should show `GET https://api.newhost.io/v2/users` and `.../orders`.
