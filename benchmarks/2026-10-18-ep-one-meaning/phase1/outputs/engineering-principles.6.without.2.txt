**Retry and logging (optional, do it after the URL swap works):**

Put this at the top of both scripts, replacing the plain `requests.get` calls:
```python
import logging
import requests
from requests.adapters import HTTPAdapter
from urllib3.util.retry import Retry

logging.basicConfig(level=logging.INFO, format="%(asctime)s %(levelname)s %(name)s: %(message)s")
log = logging.getLogger(__name__)

session = requests.Session()
retry = Retry(total=3, backoff_factor=0.5, status_forcelist=[429, 500, 502, 503, 504])
session.mount("https://", HTTPAdapter(max_retries=retry))
```

Then in `fetch_users.py`:
```python
log.info("GET %s", BASE + "/users")
resp = session.get(BASE + "/users", timeout=10)
resp.raise_for_status()
log.info("Got %s (%d bytes)", resp.status_code, len(resp.content))
```
