# docs-plan.md

Rule applied throughout: each fact has one home, and every other copy is deleted or reduced to a pointer. A pointer carries only a path or identifier, with none of the content restated.

## 1. Local setup steps
- **Canonical location:** `README.md`, in a "Setup" section.
- **CONTRIBUTING.md:** delete its copy of the steps. Replace it with one line: "Local setup: see README.md#setup".
- **CLAUDE.md:** don't repeat the steps. If it needs them, it links to the README.
- **Which version wins:**
  - The README's `npm run dev` is current. The "Lessons learned" draft says `npm start` was retired in favor of `npm run dev`.
  - "Copy `.env.example`" beats "create `.env` by hand", because the template can't drift from what the app needs.
  - `npm install` vs `npm ci` is the one open question. Check whether a lockfile is committed. If it is, `npm ci` is the better contributor default, so change the README to that. Make this edit in the README only.
- **Check before finalizing:** confirm the `dev` script exists in `package.json`. The script names there are the real definition, and the README only invokes them.

## 2. API timeout

- **README.md ("30 seconds") and CONTRIBUTING.md ("45 seconds"):** delete the number from both. The two docs disagree, so at least one is wrong, and neither can be trusted without reading the constant.
- **Replacement text:** if readers need to know a timeout exists, use a pointer only, for example "Request timeout is configured in `src/http/client.js`". Don't restate the value.
- **First step:** read the constant, so you know which doc was wrong. This is for your information only, since both numbers get deleted anyway.

## 3. Support email

## 4. The `recalcTotals()` rule
- **Current problem:** it's misplaced. It only matters in `src/billing.js`, but it sits in an always-loaded `CLAUDE.md`, where it costs context everywhere else.
- **Canonical location:** a header comment at the top of `src/billing.js`, next to the code it constrains. Example: "After any mutation to line items, call `recalcTotals()`."
- **CLAUDE.md:** delete the rule, with no pointer left behind.
- **Optional follow-up (separate scope):** have the line-item mutators call `recalcTotals()` internally. That removes the rule entirely, because the bug can no longer happen. Do it only if you want it. It isn't part of this restructuring.

- **Don't relocate it.** Don't move it to CONTRIBUTING, a CHANGELOG, an ADR, or a new history file.
- **Anything still true:**
  - The `npm run dev` fact is already covered by the README setup (item 1).
  - If the port clash still constrains anything today, state it as a present-tense rule at its home, for example the dev-server port in config or the README. Don't retell the incident.
  - The export-module rename is visible in the code, so it needs no entry.
- **Provenance:** a bare commit hash or issue number next to a rule is fine. The story around it isn't.
