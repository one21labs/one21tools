**URL change**
Putting the new URL in three places is no faster than defining it once and importing it. The single definition also means the next host move is a one-line change.

1. New file `scripts/config.py`:
```python
# Source of truth for the API base URL. Import it; do not copy it elsewhere.
API_BASE_URL = "https://api.newhost.io/v2"
```

2. `scripts/fetch_users.py`: add `from config import API_BASE_URL` at the top, then replace
```python
BASE = "https://api.oldhost.com/v2"
```
with
```python
BASE = API_BASE_URL
```
The `requests.get(BASE + "/users")` line stays as is.

3. `scripts/fetch_orders.py`: add `from config import API_BASE_URL` at the top, then replace
```python
url = "https://api.oldhost.com/v2/orders"
```
with
```python
url = API_BASE_URL + "/orders"
```

4. README: replace the line with
```
All data comes from the API whose base URL is defined in `scripts/config.py`.
```
